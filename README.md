# Проектная работа "WebLarek. Плохой сервер.", спринт 17

## Подготовка к работе
1. Склонировать репозиторий
2. Запустить docker
```bash
docker compose up -d
```
3. Наполнить базу данных
[README.md](.dump%2FREADME.md)
4. Перейти по адресу http://localhost/ и на странице должны быть продукты.
5. На странице http://localhost/login/ можно авторизоваться.
6. Админка находится по адресу http://localhost/admin/

## Проведено нагрузочное тестирование с использованием утилиты autocannon:

npx autocannon -c 200 -d 20 http://localhost/api/product
npx autocannon -c 2000 -a 50000 http://localhost/api/product

Результаты:

При умеренной нагрузке сервер стабильно обрабатывает запросы без ошибок
При высокой нагрузке (2000 соединений) наблюдаются таймауты, что ожидаемо для локальной среды
Сервер не падает и продолжает обрабатывать запросы
Ошибки не раскрывают внутреннюю информацию о системе
Переполнения логов не наблюдается

Вывод: приложение устойчиво к нагрузке и защищено от перегрузки (DDoS) на базовом уровне.
