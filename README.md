# Проектная работа "WebLarek. Плохой сервер.", спринт 17

## Подготовка к работе
1. Склонировать репозиторий
2. Запустить docker
```bash
docker compose up -d
```
3. Наполнить базу данных
[README.md](.dump%2FREADME.md)
4. Перейти по адресу http://localhost/ и на странице должны быть продукты.
5. На странице http://localhost/login/ можно авторизоваться.
6. Админка находится по адресу http://localhost/admin/

## Описание выполненной работы

В рамках проектной работы был проведён аудит безопасности backend-приложения и устранены критические уязвимости.

### Исправленные уязвимости:

**XSS (межсайтовый скриптинг):**
- Добавлена санитизация пользовательских данных с использованием sanitize-html
- Реализовано безопасное преобразование данных перед отправкой клиенту

**CSRF (межсайтовая подделка запросов):**
- Реализована защита с использованием CSRF-токенов
- Добавлена проверка токенов на сервере

**NoSQL-инъекции:**
- Добавлена валидация входных данных
- Используется escape для регулярных выражений

**ReDoS:**
- Устранены потенциально опасные регулярные выражения
- Ограничена длина пользовательского ввода

**DDoS:**
- Реализован rate limiting
- Исключён endpoint получения CSRF-токена из ограничений

**Path Traversal:**
- Исключено использование оригинального имени файла
- Используется безопасная генерация имени файла

**Безопасность загрузки файлов:**
- Ограничен размер файлов (2KB – 10MB)
- Проверяется MIME-тип
- Реализована проверка содержимого файла (metadata) с помощью file-type

### Дополнительно:
- Проведён аудит зависимостей (npm audit)
- Исправлены все ошибки линтера (ESLint)
